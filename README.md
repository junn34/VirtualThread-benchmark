# 가상 스레드 성능 검증

## 프로젝트 목적
Java 가상 스레드의 동작 방식과 성능 특성을 이해하고,
기존 스레드 모델과 비교하여 실제 서비스 환경에서의 적용 가능성을 검증한다.

## 테스트 환경
- Java: 21
- 테스트 도구: nGrinder
- 테스트 대상: CPU-bound / I/O-bound 시나리오

## 실험 내용
- 기존 스레드 모델과 가상 스레드 모델의 처리량 및 응답 시간 비교
- DB 병목 환경에서의 성능 변화 관찰

## 결과 요약
- CPU-bound 환경에서는 유의미한 성능 차이가 크지 않음을 확인
- 주요 병목이 DB 락 경합인 구조에서는 가상 스레드가
  근본적인 성능 개선으로 이어지지 않음을 확인

## 결론
가상 스레드는 모든 상황의 해결책이 아니며,
병목 지점과 시스템 구조를 고려한 제한적인 적용이 필요하다고 판단했다.
